# 전화번호 목록 : 해시맵

- 실수
  - hash[s_size].push_back[]
  - 자꾸 push_back() 가 아니라 []를 써서 오류를 낸다.
  - hash 전체를 탐색할 때, 자기자신을 발견하고 탐색을 끝내지 않도록 크기 제한을 걸어야 한다.
  - 문자열을 자를 때, 10글자이면 딱 9글자까지만 잘라야한다.
- 공부
  - 예시에서는 띄어쓰기가 있는데, 테스트케이스에는 띄어쓰기가 없다.
  - 테스트케이스를 안 봤으면 띄어쓰기 없애는 법 생각하다 탈진했을 것이다. 잘 봐라.
  - 걍 벡터에 있는걸 1:1로 해시에 value는 대충 1로 똑같이 해서 다 집어넣기만 해도 유효하다고 하다.
  - 벡터와의 차이점은 처음부터 끝까지 뒤지는게 아니라, O(1) 만에 그냥 원하는 데이터를 찾는 것이다. 이게 해시의 본질이다.
  - 그래서 걍 1:1로 집어넣는 전처리를 하는 것이다.
  - 이것을 더 효율적으로 하는 자료구조가 unordered_map이다.
  - 얘는 정렬이 안되어있는 대신, 탐색을 더 빠르게 한다고 함.
  - #include <unordered_map> 하면 된다.
  - if ()내부나 map[] 이것의 내부에 더럽게 괄호 여러개, 이름 길게 해야하면 외부에서 변수 선언해서 할당하고 써라.
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <unordered_map>

  using namespace std;

  bool solution(vector<string> phone_book) {
      unordered_map<string, int> hash;

      // 1. 모든 번호를 해시맵에 등록합니다.
      for (string number : phone_book) {
          hash[number] = 1;
      }

      // 2. 각 번호의 앞부분을 잘라가며 해시맵에 있는지 확인합니다.
      for (string number : phone_book) {
          string prefix = "";
          // 본인 전체 번호와 똑같은 경우는 제외해야 하므로 size - 1까지만 자릅니다.
          for (int i = 0; i < number.size() - 1; i++) {
              prefix += number[i]; // 한 글자씩 붙여가며 접두어 조각을 만듭니다.
              // 만들어진 조각이 해시맵에 존재하면 접두어가 있는 것입니다.
              if (hash[prefix]) {
                  return false;
              }
          }
      }
      return true;
  }
  ```
