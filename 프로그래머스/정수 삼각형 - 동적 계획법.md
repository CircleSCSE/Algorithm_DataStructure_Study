# 정수 삼각형 : 동적 계획법

- 공부
  - 동적 계획법
    - 큰 문제를 작은 문제로 나누어 푼다.
    - 그리고, 그 결과를 저장해두고 다시 쓴다.
    - 이전 단계의 최적 결과를 저장해두고 다음 단계에 쓴다.
    - 모든 경우를 처음부터 쭉 살피는 중복 연산을 확 줄인다.
  - 이전 문제에서 함수에 주어진 map에 방문 기록 ( 변화 기록 ) 을 저장해서, 중복 방문을 피한 것처럼 이 문제도, 주어진 triangle 벡터 내부의 값에 누적되는 값을 저장한다. 그리고 바로 다음 단계에서 그걸 쓴다.
  - 특정 벡터 길이를 2번 이상 쓴다면, 그걸 변수에 저장해두고 쓰자.
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <algorithm>

  using namespace std;

  int solution(vector<vector<int>> triangle) {
      int answer = 0;
      int n = triangle.size();

      for (int i = 1; i < n; i++) {
          for (int j = 0; j <= i; j++) {
              if (j == 0) {
                  triangle[i][j] += triangle[i - 1][0];
              } else if (j == i) {
                  triangle[i][j] += triangle[i - 1][j - 1];
              } else {
                  triangle[i][j] += max(triangle[i - 1][j - 1], triangle[i - 1][j]);
              }
          }
      }

      for (int i = 0; i < n; i++) {
          answer = max(answer, triangle[n - 1][i]);
      }

      return answer;
  }
  ```
- 2차 시도 : 29m ( 성공 )
  - 잘한 점들이 있다.
  - 디버깅을 스스로 직접 했다.
  - i = 0 인 경우 음수 인덱스가 나는걸 발견해서 예외처리
  - 문제를 다시 읽고, 특정 경로를 따라서 ‘그 경로 전체의 합’ 의 최댓값임을 보고, 그냥 기존에 착각해서 더하기를 안 한 사실 발견 후 수정
  - 과정에서 아래에 더 큰 것과의 합을 저장한다는 개념을 생각해보고, 기존에 한 실수인 단순히 더해서 내려보내기를 max를 통해 골라서 내려보내는 식으로 수정
- 1차 시도 : 8m ( 20m )
  - 상황 파악해보니까, 내가 지닌 지식으로 아무리 지랄해도 안 될 수수께끼인 걸 파악함.
