# 할인 행사 : 자료구조

- 공부
- 생각
  - 역시 문제 골 때리면 예시부터 보는게 낫다.
  - 첫 오류에 대한 설명은 제일 위에 빨간 글씨로 있다.
- 몰라서 써도 되나 고뇌한 부분들
  - map도 자료구조의 종류 중 하나이다.
  - [] 안에 [] 를 넣어도 꼬이는게 아니다.
  - 일단, 초기에 데이터를 주면, 처리하기 좋은 방식으로 전처리를 해두는게 좋은 것 같다. 저번에 그래프 문제에서 그래프부터 구성했듯이 말이다.
  - 반복분 내부에서 임시로 뭔가를 저장하고, 반복할 때마다 초기화하고 싶다면 그냥 선언을 반복문 안에서 하면 된다. 벡터, 맵, int 다 통용된다.
  - 전체 안에서 슬라이딩 윈도우마냥 1칸씩 옮기면서, 그 윈도우 내부를 조사하는 것
    - 2중 for문 쓰고
    - 외부는 0부터 시작에서 그 윈도우 크기를 뺀 만큼 반복하고
    - 윈도우 자체를 조사하는건 i + j 이렇게 해서, 윈도우의 위치에서 j를 반복문으로 ++ 해서 조사하는 식으로 하면 된다.
  - 그리고 target[want[i]] 이런 식으로 [] 가 겹치는 것이 이상한게 아니라는 이런 사실들을 흡수해야한다.
  - 저 형태를 처음 써보고 ‘이렇게 써도 되나? 너무 꼬이지 않나?’라고 지래짐작하고 답이 맞는데 안 쓰는 경우들이 있기 때문이다.
  - 사실 자료구조, 알고리즘 이론이 어렵다기보다 이런 정보와 경험의 공백, 그리고 라이브러리들을 직접 여러번 사용하고 적으며 여러차례 흡수하지 못했기 때문에, 더 쉽게 갈 수 있는 길이 블록, 요령처럼 있는데 그걸 본 적 없고 못 흡수해놔서 어렵게 돌아가다가 시간 초과 나는 느낌이 있다.
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <map>

  using namespace std;

  int solution(vector<string> want, vector<int> number, vector<string> discount) {
      int answer = 0;
      map<string, int> target;

      // 1. 우리가 원하는 제품과 수량을 target 맵에 등록합니다.
      for (int i = 0; i < want.size(); i++) {
          target[want[i]] = number[i];
      }

      // 2. 할인 목록을 처음부터 끝까지 순회합니다.
      // 총 10일을 확인해야 하므로 discount.size() - 10 까지만 확인합니다.
      for (int i = 0; i <= discount.size() - 10; i++) {
          map<string, int> current_window;

          // 3. 현재 날짜(i)부터 10일 동안의 할인 품목을 맵에 카운트합니다.
          for (int j = 0; j < 10; j++) {
              current_window[discount[i + j]]++;
          }

          // 4. 원하는 품목 맵과 10일치 할인 품목 맵이 완전히 동일한지 비교합니다.
          if (target == current_window) {
              answer++;
          }
      }

      return answer;
  }
  ```
- 1차 시도 : 28m ( 20m )
