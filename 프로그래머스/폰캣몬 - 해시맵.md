# 폰캣몬 : 해시맵

- 공부
  - 해시맵은 말 그대로 map이다. 가령 동물이라고 하면, 주어진 벡터에서 동물들이 그냥 분류가 안된 채로 모여있으면, 동물의 이름을 키로 담아서 마릿수를 기록하는 그런 식인 듯 하다.
  - 이해한 그대로가 맞음. 파이썬 코드보고 이해했는데, 그대로 해서 맞춤.
  - DFS에서 주어진 벡터 데이터를 그래프로 전처리하듯이, 해시에서는 map으로 전처리를 하고 나서 쓰는 느낌임.
- 정답 코드 → 내가 직접 짰음
  ```cpp
  #include <vector>
  #include <map>

  using namespace std;

  // 6마리가 있으면, 3마리를 선택 ( N이 최대 10000이다 )
  // 그때 중복 없이 가장 많은 종류를 택하는 방법 찾기
  // 그때의 최댓값 출력
  int solution(vector<int> nums) {
      int answer = 0;
      int leng = nums.size();
      int half = leng / 2;
      map<int, int> hash;

      for (int i = 0; i < leng; i++) {
          hash[nums[i]]++;
      }

      int names_cnt = hash.size();
      if (names_cnt > half) {
          answer = half;
      } else {
          answer = names_cnt;
      }

      return answer;
  }
  ```
