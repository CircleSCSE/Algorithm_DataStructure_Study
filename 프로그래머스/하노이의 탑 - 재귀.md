# 하노이의 탑 : 재귀

- 정답 코드
  ```cpp
  #include <string>
  #include <vector>

  using namespace std;

  void sol(int n, int start, int sub, int end, vector<vector<int>>& answer) {
      if (n == 1) {
          answer.push_back({start, end});
          return;
      }
      sol(n - 1, start, end, sub, answer);
      answer.push_back({start, end});
      sol(n - 1, sub, start, end, answer);
  }

  vector<vector<int>> solution(int n) {
      vector<vector<int>> answer;
      sol(n, 1, 2, 3, answer);
      return answer;
  }
  ```
- 공부
  - 재귀는 참… 그냥 그렇다.
  - 예전에 완전 처음 봤을 때보다는 흡수가 잘된다.
  - 그니까, 걍 수학적인 엄밀함과 재귀라는 아이디어는 별개인 것이다.
  - 설명을 하자면, 기둥이 3개이다. 그리고 시작, 보조, 끝 기둥이라는 개념을 정한다.
  - 아무튼 제일 밑의 가장 큰 것 외의 n - 1개를 다른 기둥으로 보내는 작업 자체를 재귀에 넣는다. 작동 원리는 잘 모르는데, 아무튼 그걸 반복 작업으로 둔다.
  - 그리고, 3단계로 한다.
    - 1번 기둥에서, 3번 기둥을 보조로 써서 2번 기둥으로 n - 1개를 다 옮기는 것
    - 1번 기둥에 남은 n 번째 원판을 3번으로 옮기기
    - 2번 기둥에 남은 n - 1개를 1번 기둥을 보조로 써서 3번으로 옮기기
  - 그냥 이게 전부이다. 이렇게 생각하고, 매개변수만 저 순서대로 넣어주면, 작동을 아무튼 한다. 왜 n - 1개를 옮기는게 저것만으로 작동이 되는 지는 아직도 모르겠다. 그냥 재귀가 원래 그런거 같다.
  - 그러니까… n - 1개를 옮긴다고 퉁칠 수 있는 이유가, 저번에 했던 문제처럼 하향식으로 파고 들어가고, 끝에 도달하면 종결짓는 방식이라 그런 것 같다.
  - 아무튼 n 번째를 옮길 것이고, 그런 목적으로 만들고, n - 1번째는 저런 방식으로 옮긴다. 사실 그걸로 제일 위의 재귀는 끝이다. 논리적으로 정답이 되었다.
  - 이제 그것을 정답으로 만들기 위해, 위에서부터 아래로 내려가면서, n - 1번째를 옮기기 위해 n - 2개의 것들로 또 같은 것을 하고, 그 다음 n - 3…
  - 이런 식으로 하다가, 끝에 도달하면 if 로 잡아서, 벡터에 내용물을 추가하고, return하고 끝낸다. 뭔가… 그러니까 전역으로 선언한 벡터가 아니라, 내부에 준 벡터여도… 함수가 void라면 그냥 return만 해도, 마치 마트료시카처럼 차곡차곡 쌓는 식으로 되는 듯하다.
  - 상향, 하향에 집착하는게 아니라
    - 외부 변수를 갱신시키고 끝내는 지
    - 아니면 끝에서 ( n = 1 등이 되거나, dfs에서 끝에 도달했거나 ) 부터 누적하며 마트료시카처럼 차곡차곡 쌓으며 올라오는 지
    - 이걸 구분하는게 중요한 듯
