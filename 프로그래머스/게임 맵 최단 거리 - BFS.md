# 게임 맵 최단 거리 : BFS

- 실수
  - 행렬과 x, y 좌표 한도
  - 걍 외워라 대가리 깨진다. 테스트에서 이거 생각하고 앉아있게?
  - maps[x][y]
    - x 좌표 : 앞에 있다, 행 좌표이다.
    - y 좌표 : 뒤에 있다, 열 좌표이다.
    - x축 이동은 그냥 행렬의 행 갯수가 한도라 생각해라.
    - y축 이동은 그냥 행렬의 열 갯수가 한도라 생각해라.
  - 인덱스를 할 때, 전체 길이를 변수에 저장한 것은 좋은데, 인덱스 자체가 0에서 시작하니까 각각에서 1을 빼야한다는 것을 잊었음.
  - maps[0] 해서 하나의 행을 가져와서 그 길이를 재면, 그게 열의 총 갯수이다. 바닥에 꽂아둔 나뭇가지 갯수 새는 느낌. 행은 나뭇가지 끼우는 홈이 파인 보관대같은 것이지.
- 공부
  - queue를 이용하는 원리가
    - 그냥 물결처럼, 같은 거리의 것들을 큐에 넣고 전부 동시에 판단하는게 맞다.
    - 핵심 if 조건이 maps[][] 의 값이 1이냐인 것이다. 그게 1이 아니고 변형되어있다는 것 자체가 이미 방문이 되었다는 표시인 것이다.
    - 그래서, 같은 거리로 동시에 가니까, 경로가 길어서 늦게 도착한 놈이 볼 때는 이미 그 지점은 값이 1이 아니라서 못 간다. 다 같은 속도로 가니까.
    - 기본적으로 한 점에서, 원형으로 1칸씩 퍼지며 나가는거니까. 경로가 갈라져서, 큐에 그 분기를 다 넣더라도, 더 빠른 경로로 간 녀석은 결과적으로 더 빨리 끝난다.
    - 결과적으로 가장 빠른 경로만 남는다.
  - 2차원 평면에서, 칸이 있고, 특정 지점에서 다른 지점까지의 가장 빠른 길을 찾는 문제 큐를 이 BFS가 정석이라고 한다.
  - 애초에 프로그래머스는, main에서 하는게 아니라 solution이라는 함수에 넣어서 한다.
  - 그래서 안으로 들어오는 maps 등은, 이미 복사본으로서 주어진 것이다.
  - 그러니까 매개변수 maps를 갖고, 그 함수 안에서는 원본을 바꾸듯이 쓸 수 있는 것이다. 굳이 별도로 또 복사본을 만들 필요가 없다.
  - 특정 유형에서 자주 쓰이는, 좀 특정 용도의 값을 담는 짧은 변수 이름도 외워두면 좋을 듯
    - BFS에서의 x, y 끝부분 좌표는 n, m
    - 그리고 임시 x, y 좌표들은 dx, dy, nx, ny 등으로
  - DFS는 한 쪽 끝으로 그냥 일단 다 파고 들어간다. BFS는 물결 퍼지듯이, 주변을 만지작거리면서 단계적으로 탐색해서 반드시 최단 경로가 된다.
  - 조건문 안에 &&, || 가 3개 이상 들어있어도 이상한게 아니다.
  - BFS 문제라고 if를 적게 쓰는게 아니다. 그냥 여러개 써도 이상한게 아니다. 브루트 포스처럼 걍 하면 된다.
- 정답 코드
  ```cpp
  #include <vector>
  #include <queue>

  using namespace std;

  int solution(vector<vector<int>> maps) {
      int n = maps.size();
      int m = maps[0].size();

      // 상하좌우 이동을 위한 방향 배열
      int dx[4] = {-1, 1, 0, 0};
      int dy[4] = {0, 0, -1, 1};
      // 이 둘을 i로 동시에 돌면서 좌, 우, 하, 상을 탐색한다.

      // BFS를 위한 큐 생성 (좌표 저장)
      queue<pair<int, int>> q;
      q.push({0, 0});

      while (!q.empty()) {
          int x = q.front().first;
          int y = q.front().second;
          q.pop();

          // 현재 위치에서 4가지 방향으로 위치 확인
          for (int i = 0; i < 4; i++) {
              int nx = x + dx[i];
              int ny = y + dy[i];

              // 맵 범위를 벗어나는 경우 무시
              if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;

              // 벽(0)인 경우 무시
              if (maps[nx][ny] == 0) continue;
              // 무시해야하는 상황, 오류날 상황은 그냥 continue로 넘기는게 BFS 방식인 듯

              // 해당 노드를 처음 방문하는 경우에만 최단 거리 기록 후 큐에 삽입
              if (maps[nx][ny] == 1) {
                  maps[nx][ny] = maps[x][y] + 1;
                  q.push({nx, ny});
              }
              // 지금 방문하는 곳에, 이전에 방문한 곳의 누적된 값에 1을 더하여 새로 할당한다.
              // 이렇게 하면, 중복 방문도 피할 수 있다 ( 1이 아니게 되니까 )
              // 그리고, 최단거리 값도 누적되게 된다.
              // 그래서 목적지 좌표의 값만 확인 하면, 누적된 상태를 보고 도달을 했는 지,
              // 못했는 지, 했다면 얼마가 누적이 됐는 지도 알 수 있다.
          }
      }

      // 목적지에 도달할 수 없는 경우 (값이 초기값 1 그대로인 경우)
      if (maps[n - 1][m - 1] == 1) {
          return -1;
      }

      // 목적지에 기록된 최단 거리 반환
      return maps[n - 1][m - 1];
  }
  ```
- 2차 시도 : 25m ( 20m )
  - 거의 다 직접 풀었다.
  - 행렬과 좌표의 특성을 몰라서 막혔다. 외우고 넘어감.
- 1차 시도 : 27m ( 31m )
