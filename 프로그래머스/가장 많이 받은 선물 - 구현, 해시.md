# 가장 많이 받은 선물

- 생각, 공부
  - 자주 쓰는 코드는 덩어리는 영어 어휘, 빈출 구문집처럼 외워야 한다. 거기서 멈칫하면 바로 끝이다.
    - sstream ( 공백 나누기 )
    - vector 최대 최소
    - 이차원 벡터 선언 및 초기화
    - map 사용법
      - 이것들만 외워두고 흡수해두면, 그냥 조립해서 푸는 문제였다.
- 실수
  - 양 끝끼리만 비교했다. 이중 반복문으로 촘촘히 비교해야 했다.
    - 이런 것도 이런 문제에서 필요한 것이다.
  - 문제 조건을 놓쳐서, 빼야할 걸 못 뺐다.
- 1차 시도 : 33m
- 내가 짠 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <sstream>
  #include <numeric>
  #include <algorithm>

  using namespace std;

  int solution(vector<string> friends, vector<string> gifts) {
      int answer = 0;
      int n = friends.size();
      vector<vector<int>> present(n, vector<int>(n, 0));

      for (string i : gifts) {
          string input = i;
          stringstream ss(input);
          string first, second;
          ss >> first >> second;
          int f_i, s_i;
          for (int i = 0; i < n; i++) {
              if (first == friends[i]) {
                  f_i = i;
              }
              if (second == friends[i]) {
                  s_i = i;
              }
          }
          present[f_i][s_i]++;
      }

      vector<int> indi;
      for (vector<int> k : present) {
          indi.push_back(accumulate(k.begin(), k.end(), 0));
      }

      vector<int> res(n, 0);
      for (int i = 0; i < n; i++) {
          if (present[i][n - 1 - i] > present[n - 1 - i][i]) {
              res[i]++;
          } else if (present[i][n - 1 - i] < present[n - 1 - i][i]) {
              res[n - 1 - i]++;
          } else {
              if (indi[i] > indi[n - 1 - i]) {
                  res[i]++;
              } else if (indi[i] < indi[n - 1 - i]) {
                  res[n - 1 - i]++;
              } else {
                  continue;
              }
          }
      }

      auto it = max_element(res.begin(), res.end());
      answer = *it;
      return answer;
  }

  // 다음 달 가장 많이 받을 놈
  // A <-> B : 서로 주고받은게 덜 받은 놈에게 더 받은 놈이 1개 주기
  // 같다? : 지수가 더 낮은 놈이 받기 ( 여기서는 지수 따질 필요 없음 )
  // 지수 : ( 지가 총 준 수 - 받은 수 )
  // 지수까지 같으면 아무도 못 받음
  // gifts 내부 : "A B" -> a가 b에게 줌
  ```
