# 주식 가격 : 큐/스택

- 실수
  - while 안에서 스택의 뭔가를 top()으로 뽑아서 비교를 해야할 때, 반드시 조건에 !s.empty()를 넣어야 한다. 없는 것을 빼려하면 범위 초과 오류가 뜬다.
  - 빈 스택이나 빈 큐에서 없는 것을 빼려고 해도 dump가 난다.
- 공부
  - 범위 초과 오류가 어디서 난 지를 알기 위해 덩어리들을 각각 주석 처리 하며 좁혀갔다.
  - 주석 처리하면 dump에서 일반 실패로 바뀌는 부분에서 오류가 난 것이다.
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <iostream>
  #include <stack>

  using namespace std;

  // 가격이 특정 시점 미만인 것이 안 나오는게 유지된 시간을 넣음
  // 1, 2, 3, 2, 3
  // 스택에 넣는다. 스택의 제일 뒤보다 작은게 나오면, 스택.top을 빼버리고 또 그 앞의 것과 비교한다. ( 반복 )
  // 어차피 이러면 같거나 더 큰 게 나올 때만 스택에 쌓이니까, 자연스럽게 된다. ( 오름 차순으로 들어갈 듯 )
  // 비교를 다 하고 스택에 그 작은걸 넣는다.
  vector<int> solution(vector<int> prices) {
      vector<int> answer(prices.size());
      stack<int> s; // 인덱스를 넣기

      for (int i = 0; i < prices.size(); i++) {
          if (i == 0) {
              s.push(i);
          } else {
              while (!s.empty() && prices[s.top()] > prices[i]) {
                  answer[s.top()] = i - s.top();
                  s.pop();
              }
              s.push(i);
              // cout << s.top() << endl;
          }
      }

      while (!s.empty()) {
          answer[s.top()] = prices.size() - s.top() - 1;
          s.pop();
      }

      return answer;
  }
  ```
- 1차 시도 : 30m ( 5m )
  - 딱 한 줄 틀려서 범위 초과 ( segment dump ) 뜸
