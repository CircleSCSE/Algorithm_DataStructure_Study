# 소수 만들기

- 문제 파악
  - // nums 의 숫자 갯수는 최대 50개
  - // nums 의 원소 크기는 최대 1000, 중복 없음.
  - // 3개 더해서 소수인 것?
  - // 1과 자신 외에는 약수가 없어야 함.
  - // 최대 998, 999, 1000 을 더한 것들까지. 즉, 3개를 더한 것들 1부터 (자기 크기 - 1)까지 나눴을 때 나머지가 0이 되는게 하나라도 있으면 소수가 아님.
  - // 3개를 더하려면 3개를 골라야 함. 3개를 어떻게 고르지?
  - // 3중 for문? 걍 브루트 포스로 싹 돌아야하나?
- 코드
  - 1차 작성
    ```cpp
    #include <vector>
    #include <iostream>

    using namespace std;

    int solution(vector<int> nums) {
        int answer = -1;
        int my_sum, count = 0;
        bool passed;

        // i = 0, j = 1, k = 2, 3, 4 ~~
        for (size_t i = 0; i < nums.size(); i++) {
            for (size_t j = i + 1; j < nums.size(); j++) {
                passed = false;
                for (size_t k = j + 1; k < nums.size(); k++) {
                    my_sum = nums[i] + nums[j] + nums[k];
                    for (int q = 2; q < my_sum; q++) {
                        if (my_sum % q == 0) {
                            break;
                        }
                    }
                    bool passed = true;
                }
                if (passed) {
                    count++;
                }
            }
        }

        answer = count;
        return answer;
    }
    ```
