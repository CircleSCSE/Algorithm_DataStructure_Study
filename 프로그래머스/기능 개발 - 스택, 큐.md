# 기능 개발 : 스택, 큐

- 실수
  - 남은 % ( 100 - progresses ) 에서 매일 진행 가능한 %를 나눈 나머지를 if에 넣어야 하는데, 실수로 그냥 progresses만 넣었다.
  - 이런 식으로 큐 문제임에도, 데이터 전처리에서의 조건 로직에서 어이없는 실수를 하는 경우가 있다는 점을 배웠다.
  - 그리고 ‘데이터 전처리’라는 발상이 매우 유용하다. 뭔 문제에든 적용 되는 듯.
- 공부
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <queue>
  #include <iostream>

  using namespace std;

  // 출력은 한번에 배포되는 갯수만 넣음 ( 배포된 날짜는 필요 없음 )
  // 각 작업의 이미 완성된 % 배열 ( 최대 100개 ) / 각 작업이 하루당 진행하는 % 배열
  // 배포는 앞에서부터 진행, 뒤의 것이 먼저 완성되어도 앞의 것과 함께 배포
  // 앞의 것의 배포 소요일이 더 작으면 걔랑 같이 배포
  // 큐에 차례대로 넣어서, 제일 앞의 것보다 소요일이 작은게 연속되는 것까지 담은 뒤, 소요일이 제일 앞보다 큰게 나타나면 그 직전의 큐 크기만큼 배포하고 다 비운다.
  // 각 작업을 전처리한 배열을 구해볼까? ( 며칠이 걸리는 지만 정리해둔 벡터 )
  vector<int> solution(vector<int> progresses, vector<int> speeds) {
      vector<int> answer;
      vector<int> deploy_day(progresses.size());
      queue<int> q;

      for (int i = 0; i < progresses.size(); i++) {
          if ((100 - progresses[i]) % speeds[i] != 0) {
              deploy_day[i] = (100 - progresses[i]) / speeds[i] + 1;
          } else {
              deploy_day[i] = (100 - progresses[i]) / speeds[i];
          }
          cout << deploy_day[i] << endl;
      }

      // 데이터 전처리
      cout << endl;

      for (int i = 0; i < deploy_day.size(); i++) {
          int day = deploy_day[i];
          if (q.empty()) {
              q.push(day);
              cout << q.front() << endl;
          } else {
              if (q.front() >= day) {
                  q.push(day);
                  cout << q.front() << endl;
              } else {
                  answer.push_back(q.size());
                  q = queue<int>();
                  q.push(day);
              }
          }
          if (i == deploy_day.size() - 1) {
              answer.push_back(q.size());
          }
      }
      return answer;
  }
  ```
