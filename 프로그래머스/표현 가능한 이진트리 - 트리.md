# 표현 가능한 이진트리 : 트리

- 1차 시도 : 24m
  - 일단 2진수 변환, 전위 순회 이런걸 쓰는 것 같은데, 잘 모르겠음.
- 답지 분석
  - 일단 이진수로 변환할 때, while 조건을 잘못 적음. ( 몫이 0되면 종료 되게 해야하는데, 몫이 0인 동안 진행하라고 했음 )
  - 재귀를 이용해서 유효성을 검토하는데, 기준이 다음과 같음
    - 부모 노드가 0인데, 자식 노드가 하나라도 1이면 불가능함 ( 더미 밑에 실제가 있을 수 없으니까 )
  - 재귀를 할 때도, list로 구성된 트리에서 하는게 아니라, 문자열을 재귀에 넘긴다.
  - 이후에 start, mid, end 로 나누는데, 양 옆 노드로 파고 들어가는 탐색을 mid + 1, mid - 1 이런 식으로 한다.
- 포화 이진 트리
  - 노드 수가 무조건 2^h - 1 형태이다.
  - 1, 3, 7, 15 이런 식으로 쭉 간다.
  - 그래서 이진수 ( 0, 1 로 이뤄진 문자열 )의 길이가 4가 된다? 3개에는 담을 수 없으니 다음으로 넉넉히 큰 7개짜리에 담는 것이다.
  - 문제 조건의 결과로 더미를 붙인 이진수와, 10진수를 변환한 2진수는 성질이 다르다. 그래서 1010 이런 변환 결과가 있어도 0이 더미를 나타내는 것이 아니라서, 7개에 담아야 한다.
  - 7개라는 것은, 1010 의 앞에 0이 3개 날아간 것이다. ( 기존에 2진수를 10진수로 변환할 때, 앞부분이 0인 경우는 다 사라지므로 ) 그래서 0으로 앞을 채우면 기존의 포화 이진 트리 문자열을 복원할 수 있다.
- 답지
  ```cpp
  #include <string>
  #include <vector>
  #include <algorithm>

  using namespace std;

  // 트리가 규칙을 만족하는지 확인하는 재귀 함수
  bool checkValid(const string& bin, int start, int end) {
      // 리프 노드에 도달하면 유효함
      if (start == end) {
          return true;
      }

      int mid = (start + end) / 2; // 루트 노드이다.
      int left_mid = (start + mid - 1) / 2; // 루트의 왼쪽 절반의 정중앙에 있는 것. 즉 왼쪽 자식의 위치이다. ( 문자열이라서 이렇게 하는 듯 )
      int right_mid = (mid + 1 + end) / 2; // 루트의 오른쪽의 ~~
      // 이게, 수학적으로 선분 상에서의 중간이라서, 걍 더하고 2로 나누면 나오는 듯

      // 현재 부모 노드가 더미(0)인데, 자식 노드 중 하나라도 실제 노드(1)가 있다면 유효하지 않음
      if (bin[mid] == '0') { // string 은 인덱스를 쓸 수 있네
          if (bin[left_mid] == '1' || bin[right_mid] == '1') {
              return false;
          }
      }

      // 왼쪽 서브트리와 오른쪽 서브트리도 모두 유효해야 함
      return checkValid(bin, start, mid - 1) && checkValid(bin, mid + 1, end);
  }

  vector<int> solution(vector<long long> numbers) {
      vector<int> answer;
      for (long long num : numbers) {
          if (num == 0) {
              answer.push_back(0);
              continue;
          }

          // 1. 십진수를 이진수 문자열로 변환
          string bin = "";
          long long temp = num; // 10^15 쯤 정도 되면 int에 넣으면 터진다. long long으로 선언해라.
          while (temp > 0) {
              bin += to_string(temp % 2); // string은 더하기도 된다.
              temp /= 2;
          }
          // 나머지 연산으로 구했으므로 순서를 뒤집어야 올바른 이진수가 됨
          reverse(bin.begin(), bin.end());

          // 2. 포화 이진트리의 노드 개수(2^h - 1)에 맞춰 길이를 확장
          int len = bin.length();
          int treeLen = 1;
          while (treeLen < len) {
              treeLen = treeLen * 2 + 1; // 수열의 규칙이 있다. 이전 것에 2 곱해서 1 더하면 쭉쭉 된다.
          }

          // 부족한 길이만큼 앞부분에 더미 노드(0)를 패딩
          string paddedBin = string(treeLen - len, '0') + bin;

          // 3. 유효성 검사 시작
          if (checkValid(paddedBin, 0, treeLen - 1)) {
              answer.push_back(1);
          } else {
              answer.push_back(0);
          }
      }
      return answer;
  }
  ```
