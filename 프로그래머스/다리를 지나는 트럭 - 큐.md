# 다리를 지나는 트럭 : 큐

- 1차 시도 : 35m
  - 대기 → 건너기 → 지난 이후
  - 이 3덩이라고 간주하고 진행
  - 근데, 건너기에서 1초를 머물다 가는 로직을 못 짜겠음
  - 큐를 쓰려 했는데, 중간에 넣는 것 외에 감이 안 옴.
- 답지 분석
  - 그니까.. bridge_length 라는 변수명 자체가 힌트였다. 걍 queue에 0을 저 값만큼 집어넣은 이후에, 하나씩 빼고, count를 늘리면 시간이 지나는 방식인 것이다.
  - 벡터를 위한 idx는 별도로 변수로 만들어서, 조건에 부합하면 트럭을 올리고 idx ++ 를 했다.
  - 조건에 부합하지 않은 경우, 0을 넣어서 기존의 트럭만 앞으로 보낸다.
  - q 자체를 하나의 다리로 간주한 것이다. 그래서, 조건에 부합하면 트럭을 올리고, 한 칸씩 앞으로 가면서 트럭이 전진하고, 나중에는 빠진다.
  - 마지막 트럭이 빠져나오는 시간을 마지막에 더한다.
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <queue>

  using namespace std;

  int solution(int bridge_length, int weight, vector<int> truck_weights) {
      int answer = 0;
      int current_weight = 0;
      int truck_idx = 0;
      queue<int> q;

      for (int i = 0; i < bridge_length; i++) {
          q.push(0);
      }

      while (truck_idx < truck_weights.size()) {
          answer++;
          current_weight -= q.front();
          q.pop();

          if (current_weight + truck_weights[truck_idx] <= weight) {
              q.push(truck_weights[truck_idx]);
              current_weight += truck_weights[truck_idx];
              truck_idx++;
          } else {
              q.push(0);
          }
      }

      answer += bridge_length;
      return answer;
  }
  ```
