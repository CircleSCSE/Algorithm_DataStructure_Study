# 소수 찾기 : 완전탐색

- 실수
- 공부
  - 소수 찾는 더 효율적인 알고리즘이 있음
    - 가령 16의 경우, 1 * 16, 2 * 8, 4 * 4, 8 * 2, 16 * 1 이런 식으로 약수를 찾는다. ( 앞부분이 약수 )
    - 2로 나누어떨어지면 8로도 당연히 나누어 떨어지는 것이다.
    - 즉 4로 안 나누어떨어지는 지까지만 체크하면, 그 뒤는 당연히 안 나누어 떨어진다.
    - 이때 중간에 위치한 4는 16의 제곱근에 해당한다.
    - <cmath> 라이브러리의 sqrt()를 이용한다.
    - 이런 식으로 약수들이 대칭을 이룬다.
  - 조합 찾기
    - <algorithm>에 next_permutation 를 쓴다.
    - while(next_permutation(numbers.begin(), numbers.end()));
    - numbers는 그냥 숫자 string 그대로 넣는다.
    - numbers를 계속 조합들로 바꾸어준다.
    - 더 조합이 안나오면 그대로 종료한다. 그런 식임.
    - do { ~~ // 일단 한번 오리지널 numbers에 실행하고, while 조건으로 들어감. } while(next_permutation(numbers.begin(), numbers.end())); // 원래 이렇게 쓴다. permutation 자체 용법이다.
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <set>
  #include <algorithm>
  #include <math.h>

  using namespace std;

  // 소수 검사
  bool isPrime(int n) {
      // 2미만 소수는 없다.
      if (n < 2) return false;
      // 2부터 n의 제곱근까지 소수 검사
      for (int i = 2; i <= sqrt(n); ++i) {
          if (n % i == 0) return false;
      }
      return true;
  }

  int solution(string numbers) {
      int answer = 0;
      set<int> ans{};
      // 입력 문자열 정렬
      sort(numbers.begin(), numbers.end());
      // numbers 순열의 첫번째 문자부터 문자를 누적해가며 소수인지 비교한다.
      do {
          string tmp;
          for (int i = 0; i < numbers.size(); ++i) {
              tmp += numbers[i];
              if (isPrime(stoi(tmp))) ans.insert(stoi(tmp)); // set이므로 소수인 숫자 조합들을 중복없이 담는다.
          }
      } while (next_permutation(numbers.begin(), numbers.end()));
      answer = ans.size();
      return answer;
  }
  ```
