# 피로도 : 완전 탐색

- 실수
  - 중간에 헤맨 이유가 있다.
  - cout로 for 내부를 출력해보니, 마지막 부분에서 뭔가 이상하게 나왔다. 숫자는 제대로 나오는데 마지막만 뭔가 이상하게 나오는…
  - 보니까 정상적으로 끝까지 진행된 케이스를 if, else가 제대로 못 다루는 것이다.
  - if 밖에 둬야할 answer 갱신 코드를 else 안에 넣어서 ‘if만 끝까지 정상적으로 통과한 최고의 상황’은 갱신이 안된 것이다.
  - ‘마지막까지 진행된 경우’가 잘 처리되는 지를 체크하자.
- 공부
  - next_permutation() 을 쓰면 모든 경우의 수를 구할 수 있다. 꽤 자주 쓰네.
- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <algorithm>
  #include <cmath>
  #include <iostream>

  using namespace std;

  // 시작을 위한 : 최소 필요 ( 입장 자격 )
  // 던전 마치고 드는 : 소모 필요도
  // k = 현재 피로도 ( 체력 느낌 )
  // 각 던전의 (최소, 소모) 벡터 -> 최대 8개 (8! 그렇게 안 큼)
  // 출력 : 최대 탐험 가능 던전 수
  // 순서가 중요
  int solution(int k, vector<vector<int>> dungeons) {
      int answer = -1;
      sort(dungeons.begin(), dungeons.end());
      do {
          int box = 0;
          int k_ = k;
          for (auto a : dungeons) {
              if (k_ >= a[0]) {
                  k_ -= a[1];
                  // cout << k_ << endl;
                  box++;
              } else {
                  // answer = max(box, answer);
                  // cout << " " << endl;
                  break;
              }
              answer = max(box, answer);
          }
      } while (next_permutation(dungeons.begin(), dungeons.end()));
      return answer;
  }
  ```
