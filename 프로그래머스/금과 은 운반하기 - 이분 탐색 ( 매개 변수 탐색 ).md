# 금과 은 운반하기 : 이분 탐색 ( 매개 변수 탐색 )

- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <algorithm>

  using namespace std;

  long long solution(int a, int b, vector<int> g, vector<int> s, vector<int> w, vector<int> t) {
      long long answer = -1;
      // 탐색할 시간의 최솟값과 최댓값 설정
      long long left = 0;
      // 최악의 경우: 금 10억, 은 10억을 가장 오래 걸리는 트럭 1대가 한 번에 1씩 편도 10만 시간에 걸쳐 옮길 때
      long long right = 400000000000000LL;

      // 이분 탐색 시작
      while (left <= right) {
          // mid는 현재 테스트해볼 주어진 시간을 의미합니다.
          long long mid = left + (right - left) / 2;

          // 주어진 시간(mid) 동안 전체 도시에서 모을 수 있는 광물의 누적합
          long long total_g = 0; // 최대로 옮길 수 있는 금의 양
          long long total_s = 0; // 최대로 옮길 수 있는 은의 양
          long long total_w = 0; // 최대로 옮길 수 있는 전체 광물의 양

          // 각 도시를 하나씩 순회하며 옮길 수 있는 광물의 양을 계산합니다.
          for (int i = 0; i < g.size(); i++) {
              long long time = t[i];
              long long weight = w[i];
              long long gold = g[i];
              long long silver = s[i];

              // 트럭이 편도로 이동할 수 있는 총 횟수 계산
              // time * 2는 왕복 시간입니다. ( 편도로 오는 것 말고, 가는 것만 수송에 포함하기 때문에 이렇게 함 )
              long long move_cnt = mid / (time * 2);

              // 왕복으로 다녀오고 남은 시간이 편도로 갈 수 있는 시간 이상이라면
              // 광물을 싣고 한 번 더 갈 수 있으므로 횟수를 1 증가시킵니다.
              if (mid % (time * 2) >= time) {
                  move_cnt++;
              }

              // 트럭이 해당 시간 동안 옮길 수 있는 최대 광물 무게
              long long max_weight = move_cnt * weight;
              // 그 도시에서 시간 내에 옮길 수 있는 ( 왔다갔다 하면서 ) 최대 무게
              // 얘보다 지닌 광물이 더 많으면, 그냥 얘를 최대값으로 하면 됨.
              // 지닌게 더 적으면, 지닌 걸 최대 중량으로 하면 됨.
              // 목적은 최대 광물량을 구하는 것

              // 각 도시에서 가져올 수 있는 광물 누적
              // 도시에 있는 금의 양과 트럭이 옮길 수 있는 한도 중 더 작은 값을 더합니다.
              total_g += min(gold, max_weight);
              total_s += min(silver, max_weight);

              // 전체 광물 양은 도시에 있는 금과 은의 합과 트럭의 운반 한도 중 작은 값을 더합니다.
              total_w += min(gold + silver, max_weight);
          }

          // 주어진 시간(mid) 안에 목표치를 모두 채웠는지 확인합니다.
          // 금, 은, 전체 광물 3가지 조건을 모두 만족해야 합니다.
          if (total_g >= a && total_s >= b && total_w >= a + b) {
              answer = mid; // 일단 정답으로 기록해둡니다.
              right = mid - 1; // 더 짧은 시간에도 가능한지 확인하기 위해 탐색 범위를 줄입니다.
          } else {
              // 목표치를 채우지 못했다면 시간이 더 필요하므로 탐색 범위를 늘립니다.
              left = mid + 1;
          }
      }
      return answer;
  }
  ```
- 공부
  - 이분 탐색으로 해결한다고 함
  - 그 중에서 ‘매개 변수 탐색’이라는 응용을 쓴다.
  - 애초에 동시에 진행을 하기 때문에, 한 구역에서 시간 초과가 나지 않도록 설계되어 있다고 한다. 그러니 그 부분은 내가 생각할 필요 없다.
  - 이해를 깊이 하기보다는, 그냥 이런 부류가 나오면 공식처럼 쓰자.
  - 최소 시간을 구하는 문제를 결정 문제로 바꾸는 기법이다 ( 결정 문제는 특정 시간 T가 주어졌을 때, 그 안에 해결될 수 있는 지를 O / X로 답하는 것이다 )
  - 2개로 쪼개는걸 시간에서 한다.
  - 400조의 시간이 있다면, 200조의 시간으로 들어간다. ( 중간 )
  - 200조 만에 가능하면, 더 적은 시간도 가능할 수 있으니 앞의 덩어리로 다시 이분탐색 한다.
  - 200조 만에 안되면, 201조부터 가능하니 우측 덩어리로 진행한다.
  - worst case인 경우의 시간을 구함
  - 일반항을 뽑아보면 A / B * 2t 인데, 이걸 가장 크게 만드는 경우를 상한으로 두는 것임
  - A의 최대값, B의 최솟값, t의 최댓값을 넣고 계산하면 된다.
  - 왼쪽에서 중간 지점까지의 길이는, 직선을 떠올려라.
- 1차 시도 ( 17m 적으며 고민함 )
  - 답지 기반으로 공부함.
