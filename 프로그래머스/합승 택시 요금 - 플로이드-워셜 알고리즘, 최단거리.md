# 합승 택시 요금 : 플로이드-워셜 알고리즘, 최소비용 ( 최단거리 ) 문제

- 정답 코드
  ```cpp
  #include <string>
  #include <vector>
  #include <algorithm>

  using namespace std;

  // 최대 요금(100,000) * 최대 노드 수(200) 보다 큰 값을 무한대로 설정합니다.
  // 두 무한대를 더했을 때 int 오버플로우가 나지 않도록 적당히 큰 값을 사용합니다.
  const int INF = 40000000; // 뭔가 수가 크면 이렇게 별도로 지정을 해주네

  int solution(int n, int s, int a, int b, vector<vector<int>> fares) {
      // 2차원 벡터를 무한대로 초기화
      vector<vector<int>> dist(n + 1, vector<int>(n + 1, INF));

      // 자기 자신으로 가는 비용은 0으로 설정
      for (int i = 1; i <= n; i++) {
          dist[i][i] = 0;
      }

      // 주어진 요금 정보로 거리를 채웁니다. (양방향)
      for (int i = 0; i < fares.size(); i++) {
          int u = fares[i][0];
          int v = fares[i][1];
          int cost = fares[i][2];
          dist[u][v] = cost;
          dist[v][u] = cost;
      }

      // 플로이드-워셜 알고리즘 수행
      // k: 거쳐가는 노드, i: 출발 노드, j: 도착 노드
      for (int k = 1; k <= n; k++) {
          for (int i = 1; i <= n; i++) {
              for (int j = 1; j <= n; j++) {
                  if (dist[i][k] + dist[k][j] < dist[i][j]) {
                      dist[i][j] = dist[i][k] + dist[k][j];
                  }
              }
          }
      }

      // 최소 택시 요금 계산
      int answer = INF;
      for (int k = 1; k <= n; k++) {
          // S -> K (합승) + K -> A (A 혼자) + K -> B (B 혼자)
          int total_fare = dist[s][k] + dist[k][a] + dist[k][b];
          answer = min(answer, total_fare);
      }

      return answer;
  }
  ```
- 실수
  - 3중 벡터는 쓰면 안된다. 비효율이고, 절대 안 풀린다.
  - 그러나, 중간에 잘 끊었다. 어차피 그 길로는 시간만 버렸을 것이다. 에너지 효율적으로 써야한다.
- 공부
  - 걍 플로이드 워셜만 외워두면, 그걸로 표 구축하고 ( 블록처럼 이 알고리즘을 붙여서 해결하는거임 ) 이후 과정은 적당히 짜서 해결하면 된다.
  - 플로이드 워셜은 모든 지점에서 다른 모든 지점까지의 최단거리를 구하는데에 특화된 알고리즘이다.
  - 그니까 그래프에서 원래 간선들을 타고 들어가며 어떤 목적지에 도달해야하는데, 애초에 별도의 과정을 넣어서 각 노드에서 다른 모든 노드로 가는 최소비용을 미리 표처럼 만들어두고 쓰는 것이다. ( 비유를 하면 텔레포트 장치같은 것임. 근데 제일 싼 경로의 가격을 그대로 넣어둔 )
- 발상
  - 플로이드 워셜로 표를 짜둔 이후에는, 그냥 단순 덧셈이다.
  - 갈라지는 위치가 k라 하면, ( s에서 k까지 간 비용 + k에서 a까지 + k에서 b까지 ) 이 비용들을 합친게 가장 적은걸 고르면 된다.
  - 즉, 1 ~ n까지 그냥 k를 순회하면 된다. 모든 노드에 대해서 하는거지. 갈라서는 지점을.
